# Dataset Download Instructions

Due to GitHub's file size limit (files larger than 100 MB cannot be hosted directly), the raw Zomato Bangalore dataset is not tracked in this repository.

### Dataset Details
* **Dataset Name:** Zomato Bangalore Restaurants
* **Source Platform:** Kaggle
* **Direct Download Link:** [Kaggle Zomato Dataset](https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants)

### Setup Instructions
1. Download the archive file `zomato.csv.zip` from Kaggle.
2. Extract `zomato.csv` into this `data/` folder.
3. Ensure the file path matches:
   data/zomato.csv
